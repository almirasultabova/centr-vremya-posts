# centr-vremya-posts

Сайт согласования постов центра психологии «Время».

## Что хранится в проекте

- `index.html` — интерфейс согласования.
- `posts/<month>.md` — тексты постов по месяцам.
- `reviews/<month>.json` — статусы, комментарии и мягкие удаления.
- `api/reviews.js` — API для чтения и сохранения review-файлов.
- `vercel.json` — деплой на Vercel.

## Как работает согласование

Для каждого поста можно поставить статус:

- `✅ Всё ок` — пост принят.
- `✏️ Нужны правки` — пост требует доработки.
- `💾 Сохранить` — сохраняет комментарий.
- `📋 Копировать` — копирует пост для публикации.
- `🗑 Удалить` — скрывает пост из рабочего списка.
- `↩️ Вернуть` — восстанавливает пост из удалённых.

## Мягкое удаление

Удаление не вырезает пост из `posts/<month>.md`.

Когда пользователь нажимает `🗑 Удалить`, в `reviews/<month>.json` у индекса поста сохраняется:

```json
{
  "deleted": true,
  "deletedAt": "2026-06-25T..."
}
```

Удалённый пост:

- не показывается в обычных фильтрах;
- не попадает в «Скопировать все правки»;
- доступен в фильтре `🗑 Удалённые`;
- может быть восстановлен кнопкой `↩️ Вернуть`.

Физически удалять пост из markdown нужно только после отдельного подтверждения.

## Деплой

Проект деплоится через Vercel из ветки `main`.
После изменения `index.html`, `posts/*.md`, `reviews/*.json` или `api/reviews.js` нужно сделать commit и push в GitHub.
